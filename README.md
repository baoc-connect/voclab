# VocLab

## English

VocLab is a web application for creating, editing, validating, and publishing controlled vocabularies such as thesauri and taxonomies. It was designed for teaching and learning about knowledge organization. The interface is available in English and Spanish.

### Key features

- Import vocabularies from CSV or TSV and edit them in a spreadsheet-like interface.
- Manage multilingual labels, definitions, and scope notes.
- Build hierarchical and associative relationships, and use collections for thematic or faceted browsing.
- Detect duplicate identifiers, missing references, and hierarchical cycles.
- Explore vocabularies through alphabetical, hierarchical, and collection views, interactive graphs, and statistics.
- Publish validated vocabularies for public access and export them as CSV, TSV, Turtle, or RDF/XML. RDF exports use the W3C SKOS model.

### Get started

- [Browse public vocabularies at the University of Murcia](https://gicd4.atica.um.es/voclab). No sign-in is required.
- [Download a sample CSV](examples/voclab_prueba_grupos_jerarquicos.csv) to explore how collections and concept hierarchies work together.
- [Download VocLab from Releases](https://github.com/baoc-connect/voclab/releases) and follow the installation guide.

## Español

VocLab es una aplicación web para crear, editar, validar y publicar vocabularios controlados, como tesauros y taxonomías. Se ha diseñado para la enseñanza y el aprendizaje de la organización del conocimiento. La interfaz está disponible en español e inglés.

### Funciones principales

- Importar vocabularios desde archivos CSV o TSV y editarlos en una interfaz similar a una hoja de cálculo.
- Gestionar etiquetas, definiciones y notas de alcance en varios idiomas.
- Establecer relaciones jerárquicas y asociativas, y utilizar colecciones para navegar por temas o facetas.
- Detectar identificadores duplicados, referencias inexistentes y ciclos jerárquicos.
- Explorar vocabularios mediante vistas alfabéticas, jerárquicas y por colecciones, grafos interactivos y estadísticas.
- Publicar vocabularios validados para su consulta pública y exportarlos en CSV, TSV, Turtle o RDF/XML. Las exportaciones RDF utilizan el modelo SKOS del W3C.

### Primeros pasos

- [Consultar los vocabularios públicos de la Universidad de Murcia](https://gicd4.atica.um.es/voclab). Se puede acceder sin iniciar sesión.
- [Descargar un CSV de ejemplo](examples/voclab_prueba_grupos_jerarquicos.csv) para explorar cómo se combinan las colecciones y las jerarquías de conceptos.
- [Descargar VocLab desde Releases](https://github.com/baoc-connect/voclab/releases) y seguir el manual de instalación.
